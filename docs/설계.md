# 달새김사주 설계 (V1)

> 근거: 대표님 통합기획안 v1.0(2026-10-07), 카톡 요청(돈의 흐름 시리즈·MBTI·행운번호), 브랜드 확정(운새김 / 달새김사주 / 20~30대 여성).
> 한 문장: **사주를 중심으로 고민을 찾아주고, AI 친구가 설명하고, 실제 선택과 사건이 자동으로 새겨져 시간이 지날수록 나에게 맞춰지는 재방문형 사주 서비스.**

## 1. 화면 구조 (모바일 웹)

하단 탭 4개: **홈 · 기록 · 타임라인 · 마이**

| 화면 | 주소 | 핵심 행동 1개 |
|---|---|---|
| 홈 | `/` | 4개 입구(오늘의 운세 / 내 고민의 길 / AI 사주친구 / 나의 사주지도) + 상황 맞춤 추천 1~2개 + 돈의 흐름 띠 |
| 사주 입력 | `/profile/new` | 3단계(이름·성별 → 생년월일 → 태어난 시간) |
| 나의 사주지도 | `/map` | 오행 균형 · 성향 한 줄 · 6영역 요약 · 핵심 키워드 |
| 오늘의 운세 | `/today` | 오늘 지수 · 연애/재물/직장/건강 · 오늘의 키워드 · 이번 달 미리보기 |
| 내 고민의 길 | `/path` | 고민 → 세부 → 궁금한 핵심(3단계) → 사주 분석 → AI 상담·기록·관련 운세 |
| AI 사주친구 | `/friend` | 텍스트 상담(음성 입력·음성으로 듣기 선택) → 상담 요약 저장 |
| 달새김 기록 | `/records` | 저장한 상담·사건 목록, 원탭 피드백(잘 풀림/비슷함/달라짐) |
| 인생 타임라인 | `/timeline` | 연도별 기록 · 분야 필터 · 사건 직접 추가 |
| 돈의 흐름 | `/money` | 재물·사업·투자·부동산 4종 → 각 결과 → 오늘의 재물 보너스(행운번호) |
| 사주 × MBTI | `/mbti` | MBTI 선택(모르면 12문항 간단 테스트) → 일간 × 성향 결과 |
| 상품 상세 / 결제 / 풀이 | `/product/:id` `/checkout/:id` `/reading/:orderId` | 유료 풀이 |
| 마이 | `/me` | 내 사주·가족 사주, 구매한 풀이, 로그인, 약관 |

**단계적 노출**: 첫 방문 → 사주 입력 전에는 홈 4개 입구 + 예시. 입력 후 → 홈에 "지금 주목해볼 길" 1~2개(나이·사주·기록 기준). 기록이 3개 이상 쌓이면 타임라인 카드가 홈에 올라온다.

## 2. 돈의 흐름 시리즈 (달새김 시그니처)
"돈의 흐름"이라는 큰 주제 하나 안에서 4가지를 각각 간단명쾌하게.

| 상품 | 무료 요약 | 유료 상세(AI 풀이 장) |
|---|---|---|
| 올해의 재물 흐름 | 재물 지수·수입/지출/저축 3지표·월별 흐름 그래프·좋은 달/신중한 달·키워드 3 | 돈이 들어오는 길 / 새는 길 / 모으는 리듬 / 월별 흐름 / 나에게 맞는 돈 관리 |
| 사업운 | 사업 지수·확장/동업/성공시기·좋은 시기 | 사업 흐름 / 확장 가능성 / 동업·파트너 / 아이템 적합성 / 시작·주의 시기 |
| **올해 나의 투자 흐름** | 투자 성향(안정·균형·신중·도전) · '시장과 나의 흐름이 만나는 시기' 그래프(시장 흐름 × 나) · '이번 달, 조금 더 신중해야 할 때' | 달새김이 보는 올해의 시장 이야기 / 나의 투자 성향 / 시장과 나의 흐름이 만나는 시기 / 이번 달 신중해야 할 때 / 나에게 맞는 돈의 리듬 |
| 부동산·이사운 | 매매·전월세·이사·문서 지수 · 좋은 시기/주의 시기 | 주거 안정 흐름 / 이사하기 좋은 시기 / 매매·전월세 / 계약·문서 주의 / 내 상황 조언 |

- 투자운: 사주로 결과를 예측하지 않는다. **관리자 화면 「시장 노트」**에 운영자가 올해·이번 달 시장의 큰 흐름(최신 정보 요약)을 쓰면, 무료 요약 화면과 AI 풀이에 "달새김이 보는 시장 이야기"로 들어간다. 종목·매수·매도 언급 금지(풀이 금지어 검사).
- 결과 마지막에 **오늘의 재물 보너스**: 행운번호 6개(1~45) · 하루 1회 "다른 번호 받기" · "재미를 위한 번호이며 당첨을 예측하거나 보장하지 않아요" 문구 · 오늘의 재물 키워드 · 달새김 한마디 · 이미지 저장/공유.

## 3. 기록하는 사주 (V1 핵심 순환)
고민의 길 → AI 상담 → **자동 요약** → [저장][수정][남기지 않기] → 타임라인 → (2주 뒤) "지난 고민은 어떻게 됐나요?" 원탭 → 다음 분석·상담에 반영.
- 장문 일기를 요구하지 않는다. 요약 한 줄 + 분야 + 날짜.
- 실제 사건 직접 추가(타임라인 +): 날짜·분야·한 줄.
- AI 사주친구는 최근 기록 5개를 참고해 답한다(사용자 동의 기반, 마이에서 끌 수 있음).

## 4. 무료·유료
| 구간 | 내용 |
|---|---|
| 무료 | 오늘의 운세, 이번 달 미리보기, 사주지도 기본, 고민의 길 기본 결과, 돈의 흐름 4종 요약, 사주×MBTI 기본, 행운번호, AI 사주친구 하루 3회, 기록·타임라인 |
| 첫 결제 | **2027 신년운세**(11/20 시즌 대표 상품), 돈의 흐름 상세 4종·묶음, 연애·궁합 |
| 추가 결제 | 고민의 길 심층분석, 사주×MBTI 심층, 평생사주 |
| 반복 | AI 사주친구 30일 이용권, 이번 달 상세운세(매월) |

가격(추천안, 관리자에서 수정): `brand.config.json` → `products`. 결정기록 D7 참고.

## 5. 데이터 구조 (확장 대비)
- 모든 주요 테이블에 `site_id`(기본 `dalsaegim`). 2호 사이트는 같은 서버를 `SITE_ID=xxx` 로 하나 더 띄우거나 같은 DB 를 나눠 쓸 수 있다.
- 분리 저장 + 공통 `user_id`·`profile_id` 연결: `users` / `profiles` / `products`(adult 플래그·series) / `orders` / `readings` / `chats`(AI 상담) / `memories`(기록·실제 사건·피드백) / `market_notes`(시장 노트) / `events`(지표).
- V2·V3 자리: `memories.kind` 에 `choice`(갈림길 A/B)·`report`(연말 보고서), `products.adult`(성인궁합, 성인인증 후 노출), `profiles.mbti`·`meta`(관상·손금 결과 요약 저장 자리).

## 6. 운영 지표 (관리자 대시보드)
무료→유료 전환율 · AI 사주친구 사용률 · 기록 저장률 · 고민의 길 완료율 · 7일/30일 재방문율 · 재결제율 · 상품별 전환율.
