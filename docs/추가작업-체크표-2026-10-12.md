### 시안에서 바로잡을 것
- 화면마다 붙은 "시연본·예시·계산 연동 후" 안내 → 실제 계산 결과로 대체하고 안내 문구 삭제.
- 상담사 초상 이미지: 440px 저해상도 + 이름 글자가 그림에 박혀 있음 → **글자 없는 원본 고해상도 이미지 필요**(대표님 요청). 받기 전까지는 시안 이미지를 잘라 임시 사용.
- 재물 그래프 예시 숫자 → 엔진 월운 계산값으로.
- '연화 할매'는 신내림을 주장하지 않는다는 안내 유지.

## 3. 타사 프리미엄 재물사주 PDF — 벤치마킹

- 구성: 7장 25소절, 54쪽. 소절마다 사주 구성표(십성·음양오행·십이운성·십이신살·귀인)에 근거 위치 ①②③ 표시 → 해설. 3년 월별 재물 그래프 + 강한 시기 TOP 3, 행운 숫자·모양·색·물건.
- 검증: 달새김 엔진으로 같은 생년월일(음력 1986.2.20 자시)을 계산 → **丙寅·辛卯·壬申·庚子 완전히 일치**.
- 달새김 엔진에 이미 있음: 십성·십이운성·대운·합충. **추가할 것: 십이신살·귀인표**(표준 대조표, 비용 0).
- 반영: 재물 4종 리포트를 7장 구성 + 구성표 근거 표시 + 3년 월별 그래프 + TOP 3 시기 + 행운템으로 확장. 문장은 새로 작성(원문 복제 없음).
- 바로잡을 것: "상위 15%", "폭발 시기"처럼 근거 없는 순위·과장 표현은 쓰지 않음(기존 결정: 금융 보장 문구 금지). 점수는 엔진 계산값만.
