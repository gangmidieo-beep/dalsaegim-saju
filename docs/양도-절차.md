대표님용 안내: 인수인계서(Claude Docs) "달새김사주 인수인계서"

## 순서 (개발사 작업)
1. GitHub `gangmidieo-beep/dalsaegim-saju` → Settings → Transfer ownership → 대표님 아이디. 대표님 수락 대기
2. Railway 프로젝트 `dalsaegim-saju`(3f0ab8ce…) → Settings → Members 에 대표님 초대 → Transfer Project → 대표님 결제카드 등록
   - 문서: https://docs.railway.com/projects#transferring-to-another-user
3. web·api 서비스 Source 를 대표님 저장소로 다시 연결(대표님 GitHub 에 Railway 앱 설치)
4. 새 PostgreSQL 을 **싱가포르**에 생성 → api `DATABASE_URL` 교체, api 서비스 지역도 싱가포르로(지금 europe-west4)
   - 서버가 시작하며 마이그레이션·상품 시드 자동 실행. 관리자 0명이면 `ADMIN_EMAIL`+`ADMIN_INIT_PASSWORD`(10자 이상)로 최고관리자 1명 생성
   - 확인 후 옛 암스테르담 DB 삭제(시연 테스트 주문 포함)
5. api 변수 교체: `JWT_SECRET`(새 무작위 값 — 기존 로그인 전부 끊김), `ADMIN_EMAIL`(대표님), `ADMIN_INIT_PASSWORD`(새 값, 대표님께 따로 전달 후 첫 로그인 때 변경), `EXTRA_WEB_ORIGINS` 정리
6. 가비아 dalsaegim.com **소유권 이전**(다른 사람 명의 → 아이디 변경 아님, 유료, 평일 9~18시) → 대표님 아이디
7. 대표님 Cloudflare 에 dalsaegim.com 추가 → DNS 레코드(루트·www·api → Railway CNAME, Railway 인증 TXT) 다시 확인 → 가비아 네임서버를 대표님 Cloudflare 것으로 → SSL Full, 주황 구름
8. 사후관리용 권한 요청: 대표님 저장소 Collaborators 에 `gangmidieo-beep` 추가(필수), Railway 프로젝트 Members 초대(권장)
9. 확인: 전체 화면 걷기(대비 검사 포함)·관리자 로그인·시연 결제 1건 → 완료 안내
